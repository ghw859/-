### 项目定位
- 工行杯参赛项目，模拟银行智慧网点排队预约+AI辅助办理系统
- 三模块微服务架构，Docker Compose 编排（Day10 部署）

### 技术栈
- **前端 gonghang_vue3**: Vue 3.5 + Vite 8 + TypeScript 6 + Pinia + TailwindCSS 3 + Axios
- **后端 lingmou_backend**: Java 21 + Spring Boot 3.2 + MyBatis-Plus + MySQL 8 + Redis 7 + JWT + ZXing + Hutool
- **AI 服务 lingmou_ai**: Python FastAPI + numpy 线性回归 + 通义千问(qwen-turbo) + redis.asyncio

### 核心业务链路
预填单解析(前端正则+Python兜底) → AI材料预检(Python规则引擎) → 生成T直通码(Java ZXing二维码+CRC16) → 预约排队(分段锁防超卖) → 到店激活办理(状态机5步) → 进度追踪

### 关键实现亮点
1. 预约并发安全：64段 striped lock 解决 check-then-act 超卖
2. 双凭证体系：T直通码(21位+CRC16) ↔ V预约凭证(18位)，双格式互认
3. 审计存证：SHA-256 哈希链，prevHash 链式签名，PII脱敏
4. 信用分体系：+3办结 / -5取消 / -10超时，定时任务CAS防重复扣分
5. AI降级策略：LLM不可用时规则兜底（知识库17条话术+规则诊断）
6. 热力图算法：numpy最小二乘线性回归预测24h→切营业8时段→与前端确定性扰动对齐
7. 前后端契约管理：前端代码冻结，后端单方面适配
